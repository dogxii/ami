ami 0.5.0 将 CLI 重写为 Go 原生程序，并升级为能够读取、修改、执行和验证开发任务的轻量终端 Agent。

- 单个可执行文件，直接运行无需 Node.js。提供 macOS、Linux、Windows 的 amd64/arm64 产物与 SHA-256 校验清单；npm 保留为零依赖的可选启动器。
- 11 个内置工具，新增精确编辑、文件创建、命令执行、进程控制和完整输出续读。默认不限制工具调用次数；大文件与完整命令日志按页面进入上下文。
- 支持会话恢复、上下文自动压缩、JSONL 事件、项目指令，以及可选步骤、token 和时间预算。
- 保留多模型 Chat Completions 兼容、配置与环境变量、工作区信任、v1 JSONL 历史，以及 commit/push/rebase 工作流。JSON 文本工具兼容模式为只读。
- 文件修改检查读取版本与唯一匹配；命令支持退出码、stdin、增量轮询、超时和取消清理。shell 使用当前账户权限。

本机 macOS ARM64 测量：原生 `--version`/`--help` 启动中位数约 3.8 ms，原 Node 版本约 31 ms；这是本地启动与工具执行改善，模型请求速度仍取决于提供商。测量方法见 [性能记录](https://github.com/dogxii/ami/blob/v0.5.0/docs/performance.md)。

macOS/Linux 安装：

```sh
curl -fsSL https://raw.githubusercontent.com/dogxii/ami/v0.5.0/scripts/install.sh | sh
```

Windows 下载对应 `.exe` 并加入 PATH。npm 用户可运行 `npm install -g @dogxi/ami@0.5.0`；从旧版本升级可沿用原有配置与会话，恢复任务时会重新检查当前文件和命令状态。

本次发布要求 macOS/Linux/Windows 的竞态测试、回归测试、go vet 和安装器校验全部通过。当前命令执行不提供 PTY 或跨调用进程重接；Windows 无法可靠清理父进程已退出的孤儿进程树。
