修复 npm 安装器在配置代理的网络中下载原生二进制失败的问题。

Node 20/22 的内置 `fetch` 不会自动使用代理环境变量。安装器现在在配置 HTTP(S)/ALL_PROXY 时使用系统 `curl`，并遵循 `NO_PROXY`；普通网络仍使用 Node 内置下载。两种路径均在 SHA-256 校验成功后才替换二进制，保持零 npm 依赖。

已增加本地 HTTP 代理回归测试，并验证在代理环境中从 GitHub Release 下载、校验和安装实际二进制。0.5 系列的 Go 原生 CLI、11 个工具、会话及配置兼容保持一致。

```sh
npm install -g @dogxi/ami@0.5.1
```

macOS/Linux 也可直接安装原生程序：

```sh
curl -fsSL https://raw.githubusercontent.com/dogxii/ami/v0.5.1/scripts/install.sh | sh
```
