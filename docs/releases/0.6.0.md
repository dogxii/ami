完善配置诊断、会话维护、操作预览和更新体验，保持单个 Go 程序、零 npm 依赖。

- 配置损坏或无法读取时明确报错，支持 `AMI_CONFIG_FILE`。新增 `ami doctor` 本地诊断；`--check` 可显式验证模型连接和工具 schema，不执行工具。
- 同一会话使用系统文件锁，阻止跨进程并发恢复和活动会话删除，进程退出后自动释放。
- 新增会话详情、JSONL 导出、删除、磁盘占用和按最后使用时间清理；提供 `--dry-run`，清理再次核对时间并跳过活动会话。删除最近任务后仍可继续剩余任务。
- 授权前展示实际命令、工作目录和文件替换/创建/覆盖预览；任务结束时汇总文件工具实际修改的文件。
- 自动读取从 Git 仓库根到工作目录的项目指令，修改子目录前先向模型提供新指令。
- 更新检查成功缓存 24 小时，失败退避 1 小时。新增 `ami update --check` 和指定版本安装/回退 `ami update --to <version>`。API 重试遵循 `Retry-After` 并显示等待时间，保留真实网络错误。
- 发布后自动验收实际 npm 包与原生安装，运行真实命令，覆盖 macOS/Linux/Windows 和 Node 20/22/24。
- 官网 Ask / Run / Tools / Git 在桌面和窄屏上均为一行，模型示例改为 `gpt-6.1-sol`。

```sh
ami doctor
ami sessions prune --older-than 30 --dry-run
ami update --check
```

```sh
npm install -g @dogxi/ami@0.6.0
```
